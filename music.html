How a day runs

  1. Generate songs in Suno and download them.
  2. Drop them in, then let Assist write the titles, tags and scene art.
  3. Pick a look and hit Render all. Rendering is real time — a 3-minute track takes 3 minutes.
  4. Connect YouTube once, then Publish all.

Keep this tab visible while rendering. Browsers throttle background tabs.

YouTube access

One-time setup. Everything below stays in this browser.

  1. Open console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. OAuth consent screen → External. Add your own Google account under Test users, and add the scope youtube.upload.
  4. Credentials → Create credentials → OAuth client ID → Web application.

Writing assistant

Groq's free tier writes your titles and descriptions. Get a key at console.groq.com — no card needed.

The key sits in this browser's storage and goes only to Groq. Anyone with access to this device can read it — use a key you can rotate.

Six uploads a day, hard ceiling. The API gives each project 10,000 quota units daily; an upload costs 1,600 and a thumbnail 50. Resets at 12:30 PM IST.
Uploads arrive private. YouTube locks videos from un-audited API projects to private. Either apply for a compliance audit, or flip each one public in YouTube Studio.

What runs where

Scene art and thumbnails come from Pollinations — free, no key, rate-limited to roughly one image every 15 seconds. Writing comes from Groq with your own free key. Suno stays manual: it has no public API, and browser security stops any page here from touching your suno.com session.

Free song generation no route

Checked repeatedly. No free service generates full songs with vocals at Suno's quality and allows a browser to call it. The open models — MusicGen, Stable Audio, ACE-Step — are instrumental-first and noticeably weaker, and their hosted endpoints block browser requests outright. They would run inside the nightly workflow, but generated audio committed to a repo hits the same 1 GB Pages ceiling as the image library, and the result would be worse than what Suno already gives you free.

If that changes, this card is where it will appear. Until then the Suno tab in the Music studio writes the brief and opens the tab, which is the part that takes thinking.

Server-side providers works, but not here

NVIDIA and Hugging Face refuse browser requests outright. OpenAI is subtler and worse: it answers a request carrying obvious junk, then drops the same request once the key looks real — an edge filter aimed at stopping people embedding keys in web pages. The practical result is the same, you cannot rely on it from a browser. All three work in the nightly workflow, which runs in Node where CORS does not apply.

Add these as repository secrets and the nightly brief will use them:

NVIDIA_API_KEY nvapi-... prefers NVIDIA, falls back to Groq NVIDIA_MODEL (variable) default meta/llama-3.3-70b-instruct PEXELS_API_KEY ... stock footage lookahead

Probed live from a browser: NVIDIA blocked · OpenAI blocked · Hugging Face blocked · Pexels reachable · Groq reachable · Gemini reachable · OpenRouter reachable.

Provider probe useful

Rather than trusting any of the above, check for yourself right now. This fires a real request from this page and reports whether the response came back at all — a status code means CORS allowed it, a network failure means it did not.

No real keys are sent — each request carries a correctly-shaped but all-zero one, so a 401 is the success case. The shape matters: OpenAI's edge drops browser requests carrying a plausible credential, so probing with obvious junk reports it as working when it is not.

Pollinations video unreliable

Some free image endpoints have started exposing short video generation. It is slow, frequently fails, and the output is a few seconds at low resolution — nowhere near usable as a music video, but occasionally interesting as a background element.
